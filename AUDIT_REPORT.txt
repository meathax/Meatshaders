AUDIT SCOPE
-----------
This release contains exactly five shader families and ten presets: one
landscape and one TATE preset per family.

  CRT Easymode / CRT Easymode - TATE
  CRT Guest Advanced / CRT Guest Advanced - TATE
  CRT Lottes / CRT Lottes - TATE
  CRT Royale / CRT Royale - TATE
  CRT Royale Kurozumi / CRT Royale Kurozumi - TATE

Runtime inventory: 14 filters, four gamma LUTs, five masks, ten presets. The
target is a real 1920x1080 HDMI grid with vscale_mode=0, mask mode 1x, and no
TV-side resampling. TATE transposes the filter axes and rotates the mask; it is
not a separately fitted visual style.


SOURCE AUTHORITY
----------------
Easymode and Lottes use current libretro/glsl-shaders commit
2b2c5ee3fd8e1a3884e20ed424fd9bfbc51cbb3d. Guest uses guest.r's
crt-guest-advanced-2026-07-23-release1 archive and its verified checksum.
Royale uses current libretro/slang-shaders commit
3b0d6aa1d134a168478cd9c904a866d969f8882b, cross-referenced to
TroggleMonkey's author-owned source.

Kurozumi is intentionally not paired with current Grade. The unchanged modern
preset contains parameters removed by Grade's 2023 replacement, so that
combination silently loses the intended gamma/P22 controls and raises black.
The v7 reference uses Kurozumi's matched historical preset and Grade blob from
7f34fc7469ecc7d90e03df45d1a10975136eb712, plus one later upstream Royale fix:
the historical bloom-approx pass computes a Gaussian but accidentally outputs
its unblurred input; current Royale outputs the calculated Gaussian. Sampled
core Royale blobs are otherwise identical, apart from an irrelevant geometry
guard. This one-line hybrid is explicit and deliberate.

The Kuro source review independently verified P22/XYZ/Rec.709 and CAT02 matrix
orientation, active defaults, the 2.304 gun curve, Grade RGBA8 quantization,
the corrected 0.2007733316 bloom-approx sigma, and all 768 codes in the 16x16
RGB grille reconstruction. Exact black in the old Grade has an undefined
zero/zero hue intermediate; resolving it to finite zero is the intended and
robust result.

Full source URLs, commits, licenses, blobs, and current MiSTer revisions are in
SOURCES.txt.


HARDWARE-EXACT MODEL
--------------------
The validator models the current MiSTer scaler/mask pipeline:

  - upper eight bits of the 12-bit source fraction select 256 phases;
  - four signed 10-bit coefficients per row;
  - integer accumulation, truncation, clamping, and saturation in RTL order;
  - one nearest-line maximum-RGB adaptive control value;
  - gamma before H/V scaling;
  - v2 mask shift/add multiplication after scaling.

Source and hardware mask periods are evaluated over their complete LCM
supercell at strict output origin. Stability uses all 1080 output lines at
224p and 240p, four signal levels, and every channel. The peak/trough standard
deviation ceiling is 0.03*255 = 7.65 codes.

ONE-BY-ONE RESULTS
------------------

CRT Easymode
  The runtime coefficient/LUT/mask values remain the measured optimum. The
  authoritative source pin is corrected from Slang to the canonical GLSL
  shader. New source oracles cover a 5x5x5 RGB lattice and the literal
  per-channel anti-ring clamp on a black/white horizontal step.

  Final exact gates:
    neutral 3.591/18.1; RGB 6.433/35.4; source step 29.147/74.3.

  Partial-linear-light LUT candidates were tested and rejected because they
  worsened neutral and RGB tone, hit coefficient bounds, or destabilized the
  1080p pattern. Easymode's automatic >=400-source-line scanline cutoff cannot
  be selected by input height inside one MiSTer preset and remains a documented
  hardware limit.

CRT Guest Advanced
  The source model now follows the July 23 spatial path for arbitrary RGB,
  including chroma-dependent beam saturation, shared source terms, linear-mask
  ordering, brightboost, glow, pr_scan, and output gamma. MiSTer's one max-RGB
  control cannot reproduce independent minority-channel beams, so the fit is a
  measured RGB/neutral Pareto point rather than a gray-only optimum.

  Full RGB cube: 9.4087/42.92 -> 5.8240/20.92.
  Selector-only artifact: 21 -> 11 codes.
  Final exact neutral: 1.7466/8.63; LUT 239 levels, plateau 2, step 2.

  The old 1.237 neutral number used an encoded-mask shortcut and is not the
  same metric as v7's exact source ordering. The release's changed temporal
  afterglow is recorded but cannot be ported without a previous-frame buffer.

CRT Lottes
  The source mask is now evaluated in its real order: 1.5/0.5 multiplication
  in linear light followed by the literal piecewise sRGB encode. The previous
  pure-2.2 metric understated actual error.

  Source-kernel weight RMSE: 0.005848 -> 0.001203 (79.4% lower).
  H7 blend: 0.163618 -> source least-squares 0.22076023.
  Corrected old-asset all-code metric: 1.6120/7.07.
  Final source-H/source-shaped-V metric: 1.7253/8.07.

  The small flat-field tradeoff is accepted because the new H is much closer
  on nonuniform source images—the behavior H actually controls. V is then
  calibrated over all 256 codes without changing source beam proportions.
  Gamma stays off and the true green-lit mask origin remains fixed.

CRT Royale
  Existing runtime assets remain the best validated source projection. The
  24x24 source slot mask was exhaustively compared with legal alternatives:

    internal tile      isolated exact-mask RMS
    12 rows x 6 cols          16.352  (kept)
    12 rows x 12 cols         16.435
    12 rows x 15 cols         16.472

  Twelve columns stores two nearly identical six-pixel cycles. Fifteen columns
  introduces a five-triad cadence reset and a 120-pixel LCM beat. MiSTer 2x
  mode turns each token into a 2x2 block and destroys one-pixel phosphor detail.
  The retained 55% finite-subline V blend is the closest tested beam shape that
  remains under the 240p stability ceiling (7.00 codes).

CRT Royale Kurozumi
  The source target is fundamentally corrected: historical P22 Grade, D65,
  2.304 gun curve, pass quantization, true black, and mask-dependent
  brightpass/bloom ordering. The old 19.854 score targeted the accidental
  modern-Grade combination and is not comparable to the stricter v7 score.

  Old assets against the correct historical target:
    neutral 27.939/max179.8; projected RGB 33.724/max177.2;
    black 2.612/max10 with LUT[0] = [5,2,2].

  Final:
    neutral 27.937/max179.8; projected RGB 33.789/max177.2;
    black 0.000/max0 with LUT[0] = [0,0,0].

  Removing the false colored black lift causes the tiny RGB RMS change but
  restores the intended black exactly. Twelve V candidates, direct/scalarized
  Grade curves, RGB-aware V, and two bounded LUT refinements were rejected for
  worse complete masked/RGB error, tone steps, or stability. The retained H/V
  and 1x2 mask are therefore a deliberately bounded hardware compromise, not
  an unfinished generic search.


PATTERN DIAGNOSTICS
-------------------
All hard pattern checks pass. Seven informational report ceilings remain:

  - Guest shared max-RGB delta: 22 codes.
  - Royale selector jump: 88; shared max-RGB delta: 43.
  - Kurozumi shared max-RGB delta: 42; gray checker chroma span: 26.
  - Easymode selector jump: 40; shared max-RGB delta: 20.

These expose the same irreducible hardware facts measured by the source audit:
one shared max-RGB selector cannot equal per-channel decisions, and a v2 mask
cannot encode a P22 matrix or three independent multipliers at one pixel.
Regularizing Royale's selector was tested but exceeded the 7.65-code moire
limit, so the source/stability-safe table is retained.


KNOWN IRREDUCIBLE DIFFERENCES
-----------------------------
Easymode: nonlinear inner-tap clamp, luma-assisted rather than max-RGB control,
and automatic progressive-height branching.

Guest: temporal afterglow, broad glow spread, and per-channel beam decisions.

Lottes: full linear-light nonseparable kernels, curvature, and off-screen
sampling.

Royale: multi-pass nonseparable bloom, full 24x24 slot geometry, curvature,
misconvergence, and intermediate framebuffer behavior.

Kurozumi: Royale's limits plus a cross-channel P22 3x3 transform and the full
16x16 mask, neither representable by independent 1-D LUTs and a v2 token.
