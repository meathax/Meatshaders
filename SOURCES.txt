====================================================================
 SOURCES, LICENSES AND REPRODUCIBLE PROVENANCE - 1080p v7
====================================================================

Audit date: 2026-07-27

This pack is derived from the real shader programs named below. Git commits
and paths are immutable source locks; the Guest archive additionally has a
SHA-256 checksum. MiSTer cannot execute GLSL/Slang, so tools/targets/ contains
executable default-parameter reference math and tools/build_port.py projects
that math into the scaler, LUT and mask operations the FPGA actually exposes.

The historical Grade lock is deliberate. The current Kurozumi preset still
names old Grade parameters that disappeared when Grade was replaced in 2023,
so combining the unchanged preset with current Grade silently drops intended
gamma/color controls and raises black. This pack uses the matched historical
Grade/preset for its active P22 transform, gun response, D65 and true zero
black, while retaining current pinned Royale. Audited core Royale blobs are
identical except one intentional upstream correction: historical
crt-royale-bloom-approx.h computes a Gaussian but outputs the unblurred input;
the current blob 92af7e73... outputs the computed color. A later irrelevant
geometry guard is the only other sampled delta. The accidental modern-Grade
compatibility combination is not shipped.

The current glsl-shaders and slang-shaders locks used by Easymode, Lottes,
Guest cross-checking and Royale were still repository HEAD revisions when
rechecked on 2026-07-27.

Current RTL still uses 256 phases selected by the upper eight fractional bits,
signed 10-bit coefficient tables, a single maximum-RGB adaptive control value,
gamma before scaling, and v2 mask multiplication after scaling. A preset can
name H/V/scan/interlace filters, gamma, mask and mask orientation. It has no
programmable pass, history buffer, color matrix, curvature or arbitrary blur.


PORT IMPLEMENTATION
-------------------

The reproducible references are:
  tools/targets/easymode_ref.py
  tools/targets/guest_advanced_ref.py
  tools/targets/lottes_ref.py
  tools/targets/royale_ref.py
  tools/targets/kurozumi_ref.py

The build and hardware model are:
  tools/build_port.py
  tools/fitting.py
  tools/mister_model.py
  tools/fileio.py

The v7 audit evaluates exact RGB as well as neutral fields, the complete
source/hardware mask supercell at the declared output origin, signal-dependent
piecewise-sRGB mask behavior for Lottes, RGB shared-control behavior for Guest,
and complete 1080-line stability at 224p and 240p. Generated filters have 256
phases and signed 10-bit coefficients and are accepted through the integer RTL
model, not floating coefficient-sum estimates.

Easymode- and Guest/Royale-derived material retains the corresponding source
license status. Kurozumi is a preset over Royale; Lottes' source states public
domain. These files reproduce source behavior only within MiSTer's documented
fixed pipeline. See tools/DESIGN.md and AUDIT_REPORT.txt for the measured
mapping and irreducible limits.
